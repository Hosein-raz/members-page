## 📖 About The Project

The **Glassmorphism Members Card** is a modern, visually striking UI component designed for showcasing team members, user profiles, or personal portfolios. Built entirely with pure HTML and CSS, this project heavily features the trendy Glassmorphism aesthetic, combining frosted glass effects with vibrant, abstract geometric backgrounds.

## ✨ Key Technical Features

This project highlights several advanced CSS techniques and modern UI design principles:

* **Glassmorphism Effect:** Achieved by combining `backdrop-filter: blur(15px)` with a semi-transparent `rgba` background to create a realistic frosted glass look.
* **Abstract CSS Shapes:** Utilizes `clip-path: circle()` along with linear gradients on `::before` and `::after` pseudo-elements to generate pure CSS background artwork without relying on external images.
* **Staggered Hover Animations:** Employs CSS custom properties (variables like `--i`) combined with `transition-delay` to create a smooth, cascading reveal effect for the social media icons when a card is hovered.
* **Smooth Micro-Interactions:** Elegant `transform: translateY` animations that shift the content and reveal hidden elements seamlessly.
* **Responsive Flexbox Layout:** Ensures the cards wrap and align perfectly across different screen sizes.

## 🚀 How to Use

To integrate these Glassmorphism cards into your own project:

1. Clone the repository:
```bash
git clone https://github.com/Hosein-raz/members-page.git
```
2. Copy the HTML structure from `index.html.` Ensure you update the image paths (`src="images/..."`) to point to your own assets.
3. Import or copy the styling from `style.css` into your main stylesheet.

## 📂 Project Structure

```
members-page/
├── images/       # Contains profile pictures and social media icons
├── index.html    # The semantic structure of the cards
└── style.css     # Glassmorphism logic, clip-paths, and hover animations
```
